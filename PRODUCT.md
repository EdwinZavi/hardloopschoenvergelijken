Product Name
Working title: Hardloopschoenvergelijken

This is a working product name, not a final brand decision.

Product Goal
Build the most trusted Dutch platform for comparing and choosing running shoes.

The platform should help users move from uncertainty to confidence by combining:

powerful filtering and comparison
personal recommendation logic
trustworthy product guidance
useful reviews and price comparison
The user should not feel like they are browsing a generic affiliate site.
They should feel guided, informed, and confident enough to make a real buying decision.

The Problem We Solve
Choosing running shoes is confusing.

Most people do not know:

which type of shoe fits their running goals
what technical differences actually matter
whether they need stability, cushioning, or responsiveness
how to compare multiple models properly
which reviews to trust
where to buy the right model at a fair price
Current experiences are fragmented:

webshops push sales, not clarity
brand sites explain only their own products
review content is often shallow or generic
price comparison sites usually lack real guidance
expert-style testing is often hard to connect to personal needs
This platform should close that gap.

Core User Promise
The platform should consistently deliver these outcomes:

users understand the key differences between shoes
users know which models fit their needs
users understand why certain shoes are recommended
users can compare options without getting lost
users can find a suitable seller and price
Primary User Segments
Design for these groups from day one:

beginner runners who need guidance and reassurance
recreational runners preparing for 5k, 10k, or half marathon
returning runners who have not bought shoes in years
experienced runners comparing technical trade-offs
runners with injury concerns or support needs
runners with fit issues such as narrow or wide feet
value-driven shoppers who want a good deal without making a bad choice
The 4 Core Jobs To Be Done
The product must solve these 4 jobs:

1. Orientation
Help users understand the running shoe landscape.

2. Personal Fit
Help users find shoes that match their goals, body, preferences, and context.

3. Comparison
Help users compare multiple shoes on meaningful attributes.

4. Confidence
Help users trust the recommendation, the platform, and the final decision.

If a feature does not clearly improve one of these jobs, it should be questioned.

Product Architecture
The platform should be built around these core layers:

1. Shoe Database
A structured database with normalized shoe information.

2. Listing and Filtering Layer
Category and use-case pages with advanced faceted filtering.

3. Comparison Layer
A side-by-side comparison experience for multiple shoes.

4. Recommendation Layer
A guided choice helper that translates user input into explainable results.

5. Trust Layer
Editorial scores, methodology, expert framing, and transparent explanations.

6. Review and Retail Layer
User reviews, price comparison, seller overview, and practical buying support.

Reviews Strategy
User reviews should not be treated as generic star ratings only.

Whenever possible, reviews should be contextualized by:

type of runner
experience level
distance use case
surface
fit comments
comfort comments
durability comments
This helps future users trust reviews that are relevant to their own situation.

MVP Scope
The MVP should focus on the smallest product that still feels genuinely useful.

MVP should include:
a structured shoe data model
a first set of shoe entries
a listing page with meaningful filters
a product detail page
a comparison feature
a first version of the personal choice helper
a basic editorial scoring framework
a retailer and price section
MVP does not need to include:
perfect automation
massive editorial coverage
deep community features
advanced account systems
every running category at once
MVP Success Criteria
The MVP is successful if a user can:

understand what matters when choosing a running shoe
narrow down relevant options quickly
compare a few strong candidates
understand why one shoe suits them better than another
find a reasonable place to buy it
